01 / 06 · Demo 2 · Data flow

Ingest in Kusto. Read in OneLake.

The shared producer emits immutable sales CSV batches. This path writes to Eventhouse first, then exposes the KQL data in a format that Lakehouse engines can read.

Closest Databricks patternAuto Loader into a Unity Catalog Delta table, read by SQL or Spark. Both platforms support file-to-Delta analytics; Fabric also exposes native KQL and a managed OneLake representation.

03 / 06 · Demo 1 · Data flow

Refresh the lineage, not every file.

Fabric Materialized Lake Views read the landing folder directly and materialize both bronze and silver. No Copy activity or ingestion notebook sits in the data path.

Closest Databricks patternA Lakeflow Spark Declarative Pipelines streaming table for bronze, then a materialized view for silver. Both platforms support declarative bronze and silver layers backed by Delta.

05 / 06 · Demo 3 · Data flow

Trigger Copy for the file that arrived.

The file-created notification carries identity, not sales rows. Activator starts a Data Factory pipeline; Copy reads the specific CSV identified by the event.

Closest Databricks patternA Lakeflow Jobs file-arrival trigger starts Auto Loader to process new files. Both platforms react to file arrivals and produce a queryable Delta table.
